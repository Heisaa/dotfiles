# mango hotkeys

Generated from `config.conf`. `Super` = mod key. Tags = workspaces (per monitor).

## Basics
| Keys | Action |
|---|---|
| `Super+Return` | Terminal (foot) |
| `Super+d` | Launcher |
| `Super+Escape` | Close window |
| `Super+Shift+c` | Reload config |
| `Super+Shift+x`, then `y` | Exit mango (`Esc` cancels) |
| `Super+Shift+z`, then `h` | Hibernate (`Esc` cancels) |
| `Super+Shift+s` | Screenshot region → clipboard |
| `Super+Shift+d` / `Super+Shift+f` | Dark / light theme |
| `Super+Space` | Toggle keyboard layout (eu/se) |

## Focus & move
| Keys | Action |
|---|---|
| `Super+h/j/k/l` (or arrows) | Focus left/down/up/right (crosses monitors) |
| `Super+Shift+h/j/k/l` (or arrows) | Swap window with neighbour |
| `Super+Tab` | Previous focused window |
| `Super+a` | Swap window into master |

## Tags (workspaces)
| Keys | Action |
|---|---|
| `Super+q w e r t y u i o` | View tag 1–9 |
| `Super+Shift+q … o` | Send window to tag 1–9 (stay) |
| `Super+scroll up/down` | Prev/next tag with windows |
| `Super+grave` | Overview (all windows) |
| `Super+g` | Sticky: show window on every tag |

## Monitors
| Keys | Action |
|---|---|
| `Super+Ctrl+h/j/k/l` | Focus monitor in direction |
| `Super+Ctrl+Shift+h/j/k/l` | Send window to monitor in direction |

## Window state
| Keys | Action |
|---|---|
| `Super+f` | Fullscreen |
| `Super+m` | Maximize (keeps bar visible) |
| `Super+Shift+Space` | Toggle floating |
| `Super+left drag` | Move window |
| `Super+right drag` | Resize window |
| `Super+period` | Resize mode: `h/j/k/l`/arrows, `Esc`/`Return` to exit |

## Layouts
| Keys | Action |
|---|---|
| `Super+v` | Scroller |
| `Super+z` | Tile (master + stack, default) |
| `Super+x` | Monocle (≈ tabbed) |
| `Super+s` | Deck (≈ stacking) |
| `Super+c` | Cycle all layouts |
| `Alt+x` | Scroller: cycle width 50/80/100% |
| `Super+[` / `Super+]` | Master narrower / wider |
| `Super+Shift+[` / `Super+Shift+]` | Fewer / more master windows |

## Scratchpad
| Keys | Action |
|---|---|
| `Super+Shift+minus` | Hide window to scratchpad |
| `Super+minus` | Show/hide scratchpad |
| `Super+Ctrl+minus` | Restore hidden window |

## Media (also on lock screen)
Volume up/down/mute, mic mute, brightness up/down on the XF86 keys.

## Touchpad gestures
| Gesture | Action |
|---|---|
| 3-finger swipe | Focus in direction |
| 4-finger left/right | Next/prev tag with windows |
| 4-finger up / down | Enter / leave overview |
